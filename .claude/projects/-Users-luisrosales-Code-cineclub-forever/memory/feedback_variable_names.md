---
name: Variable naming preference
description: User prefers descriptive variable names, never single-letter variables
type: feedback
---

Always use clear, descriptive variable names. Never use single-letter variable names (e.g., `i`, `d`, `r`, `e`).

**Why:** User explicitly requested this as a coding standard for the project.

**How to apply:** In all code written or reviewed for this project, replace single-letter variables with descriptive names. For example: `index` instead of `i`, `doc` instead of `d`, `requester` instead of `r`, `error` instead of `e`.
